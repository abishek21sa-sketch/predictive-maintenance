DATA READINESS GATE

External data must earn access to each analytical capability.

CSV/JSON, server files and SQL sources are mapped into canonical asset, telemetry and maintenance contracts. The gateway verifies temporal order, identifiers, numeric condition signals, maintenance consistency and model compatibility before data is persisted. A valid dataset can still leave RUL inference NOT READY.

REAL OPERATIONAL DATA

MetroPT-3 stays a separate evidence track.

The real-data path uses MetroPT-3 railway air-compressor telemetry and the failure windows published with the dataset. The source is acquired locally and content-validated before use. Because the source does not provide certified row-level RUL labels, the system does not fabricate them or transfer the NASA RUL model. Instead, February reference data support anomaly learning and a strictly chronological model estimates entry into a documented failure horizon.

real telemetry → February reference / chronological split → anomaly + 24h failure-horizon risk → engineering consequence → optimized maintenance decision

Feature-engineered trajectories feed the selected RUL regressor. Validation is performed against a simple age-only baseline; the complex model is retained only because it improves held-out endpoint error.

OPERATIONS RESEARCH

Gurobi chooses a feasible intervention plan.

Binary decisions now choose both intervention type (maintain, inspect, or defer where permitted) and timing. Critical assets cannot be silently deferred. RUL scenarios enter the expected-cost objective and a CVaR tail-risk term; baseline plus bay/crew stress profiles enforce robust resource feasibility. Solver status, objective, best bound and MIP gap remain engineering evidence.

min E[C(x,ξ)] + λ·CVaRα(C(x,ξ))   subject to intervention choice, shop, labor, skill, parts and robust capacity constraints

05
SIMULATION

Policies are stress-tested before interpretation.

Seeded Monte Carlo stress simulation compares the optimized intervention portfolio, an earliest-RUL heuristic and run-to-failure using common random numbers. RUL error, duration variation, bay outages, technician absence and part delays perturb the same policies. These are modeled scenarios, never realized savings or causal field performance.
