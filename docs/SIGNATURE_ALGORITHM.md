# BELIEF-MAINT Signature Algorithm

Canonical executable module: `src/pdm_intelligence/fourx/signature_algorithm.py`.

BELIEF-MAINT propagates probabilistic healthy/degraded/critical/failed beliefs through a row-stochastic absorbing Markov chain and solves a crew-constrained maintenance-timing MILP using preventive cost, cumulative failure exposure, and production opportunity cost. Baselines are fixed interval, current-risk rank, and lowest-production-load scheduling.

See `docs/BELIEF_MAINT.md` and `docs/RESEARCH_VALIDATION_BELIEF_MAINT.md`.
