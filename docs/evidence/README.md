# Validation Evidence

Machine-readable release diagnostics are written under `artifacts/` by the validation scripts. V1.0 claims are governed by `docs/evidence/VALIDATION_REPORT.md`, `RELEASE_MANIFEST.json`, and the exact release acceptance results.

Evidence classes include public/simulated benchmark validation, synthetic architecture validation, mathematical verification, optimized decisions and seeded simulated consequences. These classes are intentionally not merged into a single claim of field performance.
